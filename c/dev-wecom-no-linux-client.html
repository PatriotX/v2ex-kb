企业微信 SaaS 版至今没有原生 Linux 客户端：Linux 办公只能虚拟机/Deepin-Wine/distrobox 凑合

事实置信度 中有效更新 2026-10-28

置信依据：单帖 29 回复，多人确认缺失并分享变通办法；私有部署版有 Linux 客户端为单条回复所述

主题 编程技术与运维
标签 #企业微信 #Linux 桌面 #Wine #distrobox #办公软件

摘要

2026-10-27 有人发帖号召催企业微信出原生 Linux 版：Windows 虚拟机浪费 CPU 内存，Deepin-Wine 版体验差。回复确认企微几乎是唯一不支持 Linux 的主流办公软件（钉钉、飞书都有），有人称私有部署版其实有 Linux 客户端，只是 SaaS 版不放出。网上催促被认为没用，有人建议从“不支持信创系统”角度反映。变通方式包括虚拟机、Deepin-Wine、在 distrobox 里的 Ubuntu 装 deepin 版企微，或者干脆用手机/平板处理。

  • 现状：“似乎是唯一不支持 linux 的主流办公软件呢”t/1252139 #6↗ t/1252139 #6↗；钉钉甚至推出了 arch 版本 t/1252139 #10↗
