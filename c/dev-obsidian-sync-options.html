摘要

2026-11-01 有人新买 Mac mini 问 Obsidian 怎么同步。回复几乎没人推荐官方同步，楼主自己总结“看了半天没有用官方的”。常见路线：坚果云（被提到最多）、把 vault 放进 iCloud 文件夹、Syncthing、Git（含 GitHub 同步插件）、自建 S3/对象存储（remotely-save 插件）、Self-hosted LiveSync、Fast Note Sync Service。共同的坑是多端同时编辑出现冲突、删掉的内容被另一端恢复；Git 用户建议限制只有一端 push。也有人说有了 AI 之后笔记用得少了。
