标签 #Gitea #Forgejo #GitLab #自建 #CI/CD

摘要

2026-10-26 有人要把代码从 GitHub 迁到自建，问各家方案。回复里最常见的是“公司用 GitLab、自己用 Gitea”；Forgejo（Gitea 的分叉）因兼容 GitHub Actions 被推荐；也有 Gogs、Phorge、腾讯 Coding 等。关注点集中在 CI/CD 语法兼容（GitHub Actions 迁 GitLab CI 要重写）、大仓库迁移性能、安全漏洞和备份。
