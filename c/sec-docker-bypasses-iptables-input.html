Docker 端口映射绕过 iptables INPUT 白名单：漏洞还是特性？

分歧置信度 中有争议更新 2026-10-19

置信依据：现象被广泛知晓，定性有分歧

主题 安全与隐私 编程技术与运维
实体 Docker
标签 #Docker #iptables #防火墙
本卡片存在实质分歧或被反驳，请结合“反方 / 局限”阅读。

摘要

使用 -p 映射端口后在 INPUT 链写白名单，非白名单 IP 仍可访问，因为 Docker 自行插入 DOCKER 系列链绕过 INPUT。楼主建议在 /etc/docker/daemon.json 关闭 Docker 的 iptables 管理并手动维护规则。

证据

  • 原帖：t/1147750；楼主列举需要在 OS 内防火墙做白名单的场景 t/1147750 #6

反方 / 局限

  • 反方：十年前就有 issue，官方定性为 feature；主流云平台应用云防火墙而非仅靠 iptables —— t/1147750 #5
  • 有人认为楼主对 NAT/INPUT 链理解有误 —— t/1147750 #8、t/1147750 #10
